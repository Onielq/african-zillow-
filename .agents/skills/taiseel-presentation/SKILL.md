# Taiseel Presentation Skill

1. Read docs/PRESENTATION_WORKFLOW.md and gather source files before drafting.
2. Write down the audience, decision the presentation should support, and the one main message per slide.
3. Use actual source records and calculations; preserve dates, units, methodology, caveats, and source links.
4. Distinguish verified facts, source-reported snapshots, derived estimates, and scenario assumptions.
5. Keep maps and diagrams geographic and data-accurate; avoid unsupported market metrics or invented product capabilities.
6. Generate editable PPTX output and review the exported deck before delivery.
7. Check every chart label, title, footnote, source link, and table against the source data.

Use the official [PPT Master](https://github.com/hugohe3/ppt-master) skill only in an agent environment where it is correctly installed and its own integrity and routing checks pass.
