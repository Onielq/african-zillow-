# Investor and Market Presentation Workflow

PPT Master belongs to the presentation workflow, not the live map application. Do not add its Python requirements or slide-generation dependencies to the web runtime.

## Appropriate uses

- Taiseel investor pitch and fundraising deck
- Rwanda land-market report
- Parcel intelligence product walkthrough
- Quarterly product and data-readiness updates
- Property-investment case studies based on verified records

## Evidence rules

- Use only numbers found in a source file, source page, or recorded calculation.
- Put the observation date, source, units, and calculation method next to each material market statistic.
- Distinguish actual observations, source-reported snapshots, derived estimates, assumptions, and illustrative examples.
- Never reuse Dubai or foreign market figures as Rwanda evidence.
- Do not imply that a mapped parcel establishes legal title, ownership, encumbrance status, current availability, or a guaranteed price.
- When the source does not establish a claim, label it as unknown or leave it out.

## Production rules

Use editable PPTX output. Prefer one message per slide, purposeful diagrams, legible charts, and a consistent brand token set. Keep the source material and generated files together so claims can be audited. Review the exported file in a presentation renderer before delivery.

Official workflow reference: [PPT Master](https://github.com/hugohe3/ppt-master). Invoke it only when a presentation is actually requested; its installation and integrity checks belong in the chosen agent's local environment.
